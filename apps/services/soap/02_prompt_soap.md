1. Eres el encargado de diseñar una estructura XML para un sistema de administración que gestiona una librería en línea.

2. Crea un archivo XML llamado libreria_eg/apps/services/soap/library.xml con el diseño tomando como base el esquema de la base de datos de postgres en la ruta data/db_schema.sql.

3. La raiz del diseño del XML debe de llamarse library, y debe de tener libros con las siguientes características: ISBN, título, autor, año de publicación, género, precio, stock, formato, imágenes y conceptos definidos por libro.

4. EL diseño debe de estar en el idioma inglés y debe de usar los  datos del archivo data/library_data.sql

5. Usa el ISBN como atributo de cada libro.
