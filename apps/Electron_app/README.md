# Catálogo de Libros - Cliente Electron

Esta aplicación de escritorio multiplataforma está construida con Electron y se encarga de consumir un microservicio XML que expone un catálogo de libros.

## Instrucciones para ejecutar en Windows 11

Debido a la naturaleza basada en Node.js de Electron, el proceso en Windows 11 es estándar y no requiere dependencias específicas de Linux.

### Requisitos Previos
1. **Instalar Node.js:** Descarga e instala la versión LTS (recomendado 20.x o superior) desde [nodejs.org](https://nodejs.org/).
2. Asegúrate de que npm (Node Package Manager) esté instalado y disponible en tu terminal (`cmd` o `PowerShell`).

### Pasos de Ejecución
1. Abre tu terminal (PowerShell o Símbolo del sistema) en Windows 11.
2. Navega hasta el directorio de la aplicación:
